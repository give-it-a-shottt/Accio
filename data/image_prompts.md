# 상품 이미지 프롬프트 (키워드 55개)

구글 플로우 등에 그대로 붙여 넣고, 마음에 드는 1~2장을 `scripts/images_in/{파일 이름}` 으로 저장한다.
2장이면 `-1`, `-2` 로. 다 넣은 뒤 `uv run python scripts/prepare_images.py build`.
